3. VIỆC BẠN LÀM NGAY: GÁN GOLD BẰNG MẮT

a) Mở out/m2/label_gold.html bằng trình duyệt.
b) Nhập tên thật của bạn ở ô người gán nhãn.
c) Xem cả hai ảnh trong từng cặp; chọn:
   - 1: near-duplicate/cùng nội dung nguồn, có thể bị crop/sáng/nén.
   - 0: không phải near-duplicate; cùng màu/camera/thời gian chưa đủ để kết luận.
   - Không chắc: để trống, không đoán để đủ số lượng.
d) Chọn loại case ĐÃ XÁC NHẬN bằng mắt: exact/transformed/burst/color_trap/other.
e) Viết lý do nhìn thấy trên ảnh. Không chỉ ghi "AI nói trùng" hoặc "hash giống".
f) Dùng "Tải bản nháp" để sao lưu tiến độ nếu chưa xong.
   Trình duyệt có thử lưu tự động, nhưng một số browser chặn localStorage cho
   file local; hãy tải bản nháp trước khi đóng cửa sổ.
g) Nhãn cuối cần 30–50 cặp và đủ bốn loại theo phân công. Có thể bỏ cặp chưa chắc.
   Nếu ứng viên chưa đủ loại thật: xem thêm fixtures và bổ sung thủ công; không
   gán ép loại case. Tập ứng viên là kết quả tìm kiếm, không phải ground truth.
h) Bấm "Xuất gold hoàn chỉnh". Trình duyệt tải gold_pairs.csv.
i) Chép file đã xuất đè đúng data/gold/gold_pairs.csv trong checkout M2 này.
   Bản trong repo đã có 47 cặp hoàn chỉnh; không ghi đè bằng draft cũ chưa gán.

Schema file cuối:
img_a,img_b,is_dup,note
Luôn img_a < img_b; note từ trang sẽ kèm tên bạn, loại case và lý do.

Kiểm tra sau khi chép:
python -m src.t05_baseline --check-gold data/gold/gold_pairs.csv

Lệnh phải thành công rồi mới bàn giao cho M4. Đây là gold DEV được dùng để tune,
không được báo điểm trên nó như kết quả holdout độc lập.

Khôi phục bản nháp nếu cần:
- Chép gold_pairs_draft.csv đè data/gold/gold_pairs.csv.
- Chạy python -m src.t05_baseline --prepare-gold
- Mở lại trang. File nhãn hiện có sẽ không bị generator ghi đè.
- Nếu cần đổi trình duyệt, note chứa type=... giúp bạn chọn lại loại case.

4. CHẠY HAI BASELINE

Baseline A — random split per image:
python -m src.main --config configs/lab.yaml --output out/baseline_random --run-name baseline_random --pipeline src.t05_baseline --offline --seed 42

Baseline B — exact SHA-256; lệnh tương thích thông báo team:
python -m src.main --config configs/lab.yaml --output out/baseline --run-name baseline --pipeline src.t05_baseline --offline --seed 42

Cả hai thư mục có suspect_pairs.csv, split_manifest.csv, baseline_summary.json,
decision.json và run_info.json. Không commit out/.
--run-name baseline_exact hoặc baseline_b cũng chọn exact; baseline_a chọn random.
Nếu M1 muốn chọn qua config, có thể dùng params.baseline_method=random|exact;
M2 không tự sửa cấu hình chung. Mặc định baseline là exact để giữ lệnh team hiện tại.

HOLD của baseline là đúng: baseline không phải khuyến nghị release.

6. GIT VÀ BÀN GIAO

Git author cho M2 được người dùng xác nhận là kasdie. Kiểm tra identity trước commit:
git config user.name
git config user.email

Sau khi gold hoàn chỉnh và test đạt, kiểm tra và stage các file của M2:
git diff -- src/t05_baseline.py
git status --short
git add src/t05_baseline.py tests/test_t05_m2.py data/gold/gold_pairs.csv reports/M2_START.txt
git diff --cached
git commit -m "M2: add reproducible baselines and manually labelled gold pairs"

Chỉ dùng mô tả "manually labelled" khi chính bạn đã hoàn tất gán nhãn thật.
Nếu commit code trước, đổi mô tả thành "M2: add random and exact baselines" và
chưa stage gold draft như thể đó là gold đã dùng được.

Theo thỏa thuận với M1, push nhánh M2 và gửi commit/PR; đừng force-push hoặc tự
merge nhánh chung. Trạng thái xuất bản cuối được báo riêng cùng commit/PR thực tế.

Handoff gửi M1/M4/M6:
- Tôi là M2; commit: ...
- Baseline A: random; baseline B (lệnh baseline): exact SHA-256.
- Đã test: ...; seed=42; input fixtures không đổi.
- Gold: ... cặp, tự xem và gán nhãn; đủ loại ...; giới hạn ...

Nhớ tự điền đúng dòng M2 trong reports/team_contributions.csv và phần mình
